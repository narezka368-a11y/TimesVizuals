Свой ClickGui

Тёмное стекло, акцентный градиент, поиск, раскрывающиеся настройки, тултипы, плавные анимации и скользящий индикатор категорий.

HUD-эдитор

RCtrl — и любой элемент двигается мышью с сеткой 2 px. Выключенные элементы видны как призрачные плашки. Позиции сохраняются сами.

Менеджер аккаунтов

Список ников, создание, удаление, Random, переключение сессии в один клик. Хранится в config/timesvizuals-alts.json.

Своё главное меню

Анимированный градиент, частицы, часы, быстрый доступ к аккаунтам и настройкам. Заменяет ванильный титульник.

Метки клиента

Бейдж ⟦TV⟧ в табе и чате для тех, кто тоже с клиентом. Список ведётся локально, есть авто-детект по маркеру.

Оптимизации

Кэш ширин текста, без blur в HUD, проекция мира без аллокаций, троттлинг опроса клавиш, ленивая пересборка списков.

Установка

Пять минут, если Fabric уже стоит.

  1. Поставь Fabric Loader для Minecraft 1.21.4 и запусти игру один раз.
  2. Скачай timesvizuals-1.0-1.21.4.jar.
  3. Положи jar в папку mods своего профиля.
  4. Добавь туда же Fabric API под 1.21.4.
  5. Запусти игру: RShift — меню, RCtrl — HUD-эдитор.
Игра не запускается / чёрный экран

Проверь, что версия Minecraft ровно 1.21.4 и установлена Java 21. Убедись, что в папке mods нет посторонних jar с названием клиента. Если экран чёрный — посмотри logs/latest.log: там будет строка об ошибке шейдеров или миксинов.

Не открывается меню по RShift

В logs/latest.log должна быть строка вида Init: 38 modules loaded. Если её нет — мод не загрузился: проверь версию Fabric Loader и наличие Fabric API.

Как работают метки клиента

Список ников локальный: себя мод добавляет сам, друзей — в настройках модуля ClientTags. Автоматически узнать, у кого стоит мод, по ванильному протоколу нельзя — сервер такую информацию не передаёт.
